## Priority outcomes

### 1. UX simplification
- Step 1: Resume upload / paste / skip (single screen)
- Step 2: 5-question Career Target Wizard
  1. Desired Role
  2. Desired Industry
  3. Experience Level
  4. Japanese Level
  5. Visa Status
- Goal: dashboard within ~30 seconds

### 2. Modern dashboard
- Hero Career DNA (Current → Target + archetype)
- Match % · Readiness % · Japan Fit %
- Action Center: exactly 3 primary actions
  - Find Jobs · Improve Resume · Interview Practice
- Quick Insights: Strengths · Gaps · Next Action (3 only)

### 3. Career DNA upgrade
- Archetypes (Travel Product Builder, Operations Strategist, etc.)
- Gaps, learning path, certifications, time-to-transition
- Opportunity Center tabs: Immediate / Growth / Stretch / Avoid

### 4. Job match scoring
Resume Experience 35% · Skills 25% · Target Role 15% · Language 10% · Visa 5% · Location 5% · Goals 5%
Visible “Why this match?” (good / missing)

### 5. Japan-focused discovery
CareerCross · Daijob · GaijinPot · TokyoDev · Japan Dev · LinkedIn Japan
Source badges + Japan Readiness badges

### 6–9. Tools & tracker
- Resume Intelligence: ATS, rewrite, achievement builder
- Interview Coach V2: categories + scored answers
- Tracker: dates, salary, notes, follow-up alerts (7 days)

### 10. Design system
Background #071B35 · Cards #102A4C · Accent #F4B400
Glassmorphism, soft shadows, large radius, premium SaaS look

### 11–16
Accessibility basics, mobile-first, PWA cache v7, tier placeholders (free/pro/premium)
